# 一起联机打 maimai —— 你这边要做的

一共 4 步，10 分钟能弄完（想在 Steam 里点「开始」进游戏的话多 1 步，见第 4 步）。
卡在哪一步直接把日志 / 截图发我。

（大厅用我搭好的那台，地址 `http://isakio.cn:20100`，你什么都不用自己开。）

## 0. 前提

- 游戏必须是 **SDEZ 1.70**，MelonLoader 是 **0.6.4**（日志开头会写）
- 曲库至少要和我招募用的那首歌一致

## 1. 放文件

文件我直接发你，或者去
[Release](https://github.com/isakio/maimai-instore/releases/latest) 一起下
（三个文件都在里面）。位置别放错：

```
<游戏根目录，就是 Sinmai.exe 那一层>\
├── Sinmai.exe
├── MaimaiSteam.exe          ← 可选，想从 Steam 启动就要（见第 4 步）
├── Mods\
│   ├── InStoreLink.dll      ← 放进 Mods（联机本体）
│   └── InStoreMatch.dll     ← 放进 Mods（让「店内マッチング」那一格显示出来）
└── InStoreLink.toml         ← 放游戏根目录，别放 Mods 里
```

一行命令装完（`git clone` 那份仓库里执行，会自动找游戏目录、顺手把启动器也拷过去）：

```powershell
powershell -ExecutionPolicy Bypass -File .\client\install.ps1
```

⚠️ 如果你 `Mods\` 里以前放过 **`WorldLink.dll`**（NyanLink 那份），**删掉它**
（或者改名成 `.disabled`）—— 它和 `InStoreLink.dll` 是同一套补丁，两个一起跑会打两遍。

`InStoreLink.toml` 内容就是这几行：

```toml
LobbyUrl="http://isakio.cn:20100"
Debug=false
```

## 2. 如果你装了 AquaMai，要关一个选项

在游戏根目录的 `AquaMai.toml` 里搜 `ForceAsServer`，改成：

```toml
[GameSettings.ForceAsServer]
Disabled = true
```

⚠️ **注释掉没用，必须写 `Disabled = true`**。
这一条不关，游戏会认为"不在店里"，联机那个分类根本不出现。

## 3. Test 模式里设两项

按住 **F1** 进 Test 模式 → 选「ゲーム設定」：

| 项目 | 设成 |
| --- | --- |
| 店内マッチングの設定 | ON |
| グループ内基準機の設定 | 基準機 |

改完退出来，**重启游戏**。

## 4.（可选）让它出现在 Steam 里

想在 Steam 库里点「开始」进游戏（顺便记时长）就多这一步：

1. 确认 `MaimaiSteam.exe` 已经在游戏根目录（第 1 步那个位置）
2. Steam → 库 → 左下角「添加游戏」→ **添加非 Steam 游戏** → 浏览，选
   `<游戏根目录>\MaimaiSteam.exe`
3. 在这个条目的**属性**里确认：起始位置 = 游戏根目录，启动选项留空

之后在库里点它的「开始」就行 —— **不用改任何 Steam 设置**，也不会弹黑框。

（原理：Steam 会把它的 overlay 注进自己启动的整棵进程树，那一层会让 `mai2hook.dll`
注入失败、游戏黑屏。启动器发现自己被 Steam 拉起来时，会把注入这一步交给计划任务，
那条链不在 Steam 的进程树里，所以是干净的。出问题看游戏根目录的 `maimaiDX.log`。）

**不想折腾 Steam 也没关系**：照旧双击你原来的 `start.bat`，一样能玩。

## 5. 启动后核对这几行

看 `<游戏根目录>\MelonLoader\Logs\Latest.log`，开头应该有：

```
MelonLoader v0.6.4
[InStoreLink] InStoreLink 0.1.0 已加载（配置 InStoreLink.toml，大厅 http://isakio.cn:20100，详细日志 关）
[InStoreLink]   ✓ PreCheckAuth → OperationManager.CheckAuth_Proc
...（一共 33 行“✓ 补丁名 → 目标方法”）
[InStoreLink] 挂钩完成，共 33 条生效
[InStoreLink] 已连接中继 isakio.cn:20101（本机伪 IP ...）
[InStoreMatch] v2.5 已加载（...AutoJump=False...）
[InStoreMatch] 挂钩成功: reinputConnectCombineData ...（一共 7 行“挂钩成功”）
```

- `[InStoreLink]` 那 33 行里出现 `✗`、或者出现 `挂钩失败`、或者没有 `v2.5`，都来找我
- 游戏内右下角会显示 `InStoreLink 连接中 / 在线 N`，那是联机状态

## 怎么玩

1. 两个人都**先进到选曲界面**
2. 我这边选好歌 → 发起招募
3. 你这边：顶上分类栏**滚到最右边那一格**，就是「店内マッチング」（蓝色图标）
   （或者按「ジャンル」→ 右箭头切到最后一格）
4. 进去等最多 10 秒，我的房间会出现 → 选中 → 进房
5. 到准备页后，**两边各按一次 NEXT**，就能开始打

## 出问题先看这里

| 现象 | 先查什么 |
| --- | --- |
| 分类栏没有「店内マッチング」 | `Mods\InStoreMatch.dll` 放了吗？日志有 `v2.5 已加载` 吗？ |
| 看得到招募但进不去 | 两边的 `Mods\` 里是不是都装了 `InStoreLink.dll`（别留旧的 `WorldLink.dll`）？ |
| 日志里一堆 `✗` 补丁 | 游戏版本多半不是 SDEZ 1.70，把日志发我 |
| 刷卡登录就弹错误框 | 已知老问题，和这次安装无关，**多启动几次**就能躲开 |
| 一直显示「現在 マッチング募集はありません」 | 我这边招募可能过期了，等我重新发起，再等 10 秒 |
| 从 Steam 点开始结果黑屏 | 看游戏根目录的 `maimaiDX.log`（会写明是哪一步），把日志发我 |

日志在 `MelonLoader\Logs\` 里，翻车了把最新那份发我。
